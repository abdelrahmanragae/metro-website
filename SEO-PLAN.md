# Metro Design Studio — SEO plan

## Target
Saudi Arabia, Egypt and Gulf countries. English-first current site; introduce genuine Arabic localized pages later. Avoid claiming physical offices where none are confirmed.

## Phase 1 — Implemented
- Unique page titles and meta descriptions for Home and About.
- Canonical URLs and basic Open Graph/Twitter metadata.
- Organization and AboutPage JSON-LD.
- Accessible homepage heading and contextual copy without altering visual design.
- robots.txt and sitemap.xml for indexable static pages.

## Phase 2 — Content and information architecture
- Create indexable dedicated service pages for Brand Strategy, Brand Identity, Arabic Branding and Packaging/Brand Experience, with real service details and case-study links.
- Add genuinely translated Arabic content with proper language routing and hreflang; don't add hreflang before translations exist.
- Add location relevance naturally (Saudi Arabia, Egypt, Gulf) in service descriptions; avoid doorway pages.
- Review headings, meaningful image alt text, content quality and internal links.

## Phase 3 — Project indexability
- Existing work is JS/Supabase-driven, shown in overlays. Generate unique crawlable project URLs and server/static HTML with title, description, canonical, social metadata, text content and cover alt text. Include only published projects in sitemap.
- Ensure projects remain synchronized with admin publishing; exclude drafts.
- Add per-project SEO fields in admin and validation; ensure SEO does not rely only on client-side JS.

## Phase 4 — Verification and measurement
- Verify site with Google Search Console via domain DNS TXT (requires domain owner action), submit sitemap, inspect URLs, review indexing and performance.
- Add social share image only after a branded asset is approved.
- Test mobile Core Web Vitals, image/video loading and accessibility.
- Track queries, impressions, clicks and conversions monthly. No ranking guarantees.

## Initial keyword themes (validate with Search Console and keyword tools)
branding studio, brand identity design, Arabic branding, brand strategy, visual identity design, packaging design, استوديو تصميم هويات, تصميم هوية بصرية, تصميم علامات تجارية, استراتيجية العلامة التجارية.
